Privacy Policy

This application is a personal, non-commercial OAuth client used strictly to synchronize, back up, and restore files within the developer's personal Google Drive account using rclone.

  • Data Collection: No data is collected, stored, tracked, or sold.
  • Data Transfer: All file transfers and authentication happen directly between the user's local device and Google's servers.
  • Tokens: OAuth access tokens are stored securely on the user's local machine via rclone.
